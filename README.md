# My IP Widget для Android

Аналог виджета My IP Widget (iOS): публичный IP, страна с флагом, город, тёмная карта с координатами и кнопка ↻.

- **4×2** — как в оригинале: время обновления, IP, страна/город и карта справа.
- **2×2** — то же без карты.
- Названия для своих IP (`203.0.113.42 = Home`) — показываются в виджете рядом с адресом.
- Выбор сервиса, через который определяется IP: Яндекс (по умолчанию), ipwho.is, 2ip.io, Cloudflare, ipify или свой URL.
- Обновление: каждые 30 минут, при смене сети (Wi-Fi ↔ мобильная, включение VPN) и по ↻.
  Во время обновления IP плавно мигает, в заголовке бегут точки.

Чистый Java, без AndroidX и сторонних библиотек. minSdk 26 (Android 8+).

## Сборка через GitHub (с телефона)

1. Создай пустой репозиторий на GitHub и залей туда содержимое этой папки.
2. Actions соберёт APK сам (вкладка **Actions**, ~3–4 мин).
3. Открой **Releases → latest → MyIPWidget.apk** на телефоне и установи
   (разреши установку из браузера, если Android спросит).

Подпись фиксированная (`debug.keystore`), поэтому новые сборки ставятся поверх старых.

## Сборка в Android Studio

Открыть папку → Run, или `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.

## Откуда данные

- IP: выбранный в приложении сервис. Местоположение — отдельным запросом по самому IP: ipwho.is → ipapi.co → ipinfo.io.
- Карта: Esri Dark Gray Canvas, перекрашенная под стиль iOS (© Esri, HERE, Garmin, © OpenStreetMap contributors);
  если Esri недоступен — OpenStreetMap в тёмной инверсии. Тайлы кэшируются на 30 дней, ключи API не нужны.

Если трафик разводится по доменам (podkop и т.п.), виджет покажет IP того маршрута, куда попадает домен выбранного сервиса.
